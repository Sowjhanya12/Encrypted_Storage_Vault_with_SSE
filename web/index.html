Encrypted Cloud Vault

Searchable Symmetric Encryption · trusted client / untrusted cloud

  • AES-256-GCM encrypts every file and filename in the trusted client before anything reaches the cloud.
  • Argon2id + HKDF-SHA256 derive each user's own K_file and K_index from their vault passphrase.
  • HMAC-SHA256 search tokens let the cloud find matches in an encrypted index without seeing keywords.
  • Account login and vault unlock are separate: your account password never derives a key.

After logging in you unlock your vault with a separate vault passphrase.

Creates a regular user account and an empty, private cloud vault. Your vault passphrase is chosen on first unlock.
